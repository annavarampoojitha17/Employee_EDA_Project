# Employee Salary Analysis using SQL and Machine Learning

## Project Overview

This project performs Employee Salary Analysis using SQL, Python, EDA, and Machine Learning techniques.

## Technologies Used

* Python
* Pandas
* NumPy
* SQLite
* Matplotlib
* Seaborn
* Scikit-learn

## Features

* SQL Integration
* Data Cleaning
* Duplicate Removal
* Data Visualization
* Correlation Heatmap
* Salary Prediction using Machine Learning

## Files Included

* cleaned_dataset.csv
* eda_report.ipynb
* README.md

## Insights

* Experience and Salary are positively correlated.
* Visual analysis helps identify outliers.
* Heatmaps help understand feature relationships.
